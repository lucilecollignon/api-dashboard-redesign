# Theming

La bibliothèque expose un système de thème à deux axes : le **preset de couleurs** (`geo2france` ou `neutral`) et le **mode d'affichage** (`light`, `dark`, ou `auto`). Les deux sont indépendants et combinables librement.

---

## Presets disponibles

### `geo2france` (défaut)

Palette officielle du projet Geo2France.

| Token | Valeur |
|-------|--------|
| `colorPrimary` | `#95c11f` (vert) |
| `colorLink` | `#0f4496` (bleu marine) |
| `colorLinkHover` | `#0D2449` (bleu foncé) |

Ce preset est rétrocompatible avec les dashboards existants (Odema, Clicnat, etc.). Il est utilisé par défaut si aucun `theme` n'est spécifié.

### `neutral`

Palette bleue générique Ant Design, sans branding Geo2France.

| Token | Valeur |
|-------|--------|
| `colorPrimary` | `#1677ff` (bleu Ant Design) |
| `colorLink` | `#1677ff` |
| `colorLinkHover` | `#0958d9` |

Utile pour des tableaux de bord génériques ou pour des clients qui apportent leur propre identité visuelle.

---

## Configurer le preset

### Via `config.ts` (recommandé)

```ts
// config.ts
export const config: DashboardConfig = {
  theme: "geo2france",  // ou "neutral"
  themeMode: "auto",
};
```

### Via `<ThemeProvider>` directement

Si vous intégrez la bibliothèque dans une application React existante sans passer par `DashboardApp` :

```tsx
import { ThemeProvider } from '@geo2france/api-dashboard';

export default function App() {
  return (
    <ThemeProvider theme="neutral" mode="light">
      {/* votre application */}
    </ThemeProvider>
  );
}
```

## Tokens de base partagés

Ces tokens s'appliquent à tous les presets et modes :

| Token | Valeur | Usage |
|-------|--------|-------|
| `borderRadius` | `4px` | Coins arrondis des composants |
| `fontFamily` | `Inter, system-ui, sans-serif` | Police principale |
| `linkHoverDecoration` | `underline` | Soulignement des liens au survol |
| `Timeline.itemPaddingBottom` | `40px` | Espacement des items de timeline |

## Override partiel

### Couleurs personnalisées

Pour surcharger uniquement les couleurs sans remplacer tout le preset, passez un objet `ThemeConfig` (usage déprécié, mais toujours supporté avec avertissement console) :

```tsx
import { ThemeProvider } from '@geo2france/api-dashboard';
import type { ThemeConfig } from 'antd';

const myTheme: ThemeConfig = {
  token: {
    colorPrimary: '#e63946',  // rouge personnalisé
  },
};

// ⚠️ Déprécié — affiche un warning console.
// La config est mergée avec geo2france par défaut.
<ThemeProvider theme={myTheme}>
  ...
</ThemeProvider>
```

> **Recommandation** : si vous avez besoin d'un preset sur mesure, contribuez une palette dans `src/theme/tokens/palettes/` plutôt que de passer un `ThemeConfig` brut.

### Typographie

La police peut être changée via le token `fontFamily` :

```tsx
const myTheme: ThemeConfig = {
  token: {
    fontFamily: 'Marianne, Arial, sans-serif',
  },
};
```

### Espacements et rayons

```tsx
const myTheme: ThemeConfig = {
  token: {
    borderRadius: 8,      // coins plus arrondis
    borderRadiusLG: 12,
  },
};
```

## Logo et branding custom

Le logo du tableau de bord est configuré dans `config.ts` via la propriété `logo` (voir la doc `DashboardApp`). Il est indépendant du preset de thème.

```ts
export const config: DashboardConfig = {
  theme: "neutral",
  logo: <img src="/mon-logo.svg" alt="Mon organisation" height={32} />,
};
```

## Tokens Ant Design utilisés dans la bibliothèque

La bibliothèque consomme les tokens sémantiques suivants. Si vous overridez ces tokens dans votre thème, l'effet sera répercuté sur tous les composants qui les utilisent.

| Token | Composants impactés |
|-------|---------------------|
| `colorPrimary` | Boutons, liens actifs, indicateurs |
| `colorLink` / `colorLinkHover` | Tous les liens `<a>` |
| `colorBgContainer` | Fond des cartes, panneaux, en-têtes sticky |
| `colorBgElevated` | Légende carte (MapLegend), popups |
| `colorBorderSecondary` | Bordure du Sider, séparateurs |
| `colorBorder` | Séparateurs du footer |
| `colorTextBase` | Labels graphiques ECharts |
| `colorText` | Texte principal des graphiques |
| `Form.labelColor` | Labels de formulaire (adapté automatiquement en dark) |

---

## Règle critique Ant Design v6

> **Ne jamais mettre de couleurs dans `baseTokens`.**
>
> Le `darkAlgorithm` d'Ant Design ne peut pas écraser les tokens couleur définis dans la configuration de base ([issue #53719](https://github.com/ant-design/ant-design/issues/53719)). Toutes les couleurs sont donc définies exclusivement dans les palettes (`tokens/palettes/`) et les thèmes complets (`themes/`).
