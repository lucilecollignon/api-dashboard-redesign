# Introduction



## Installation & mise en route

### Installer nvm et Node.js

- Sur Windows : [https://github.com/coreybutler/nvm-windows?tab=readme-ov-file#install-nvm-windows](https://github.com/coreybutler/nvm-windows?tab=readme-ov-file#install-nvm-windows)
- Sur Linux : `apt install nvm`

Ensuite, depuis un terminal ([Powershell](https://learn.microsoft.com/fr-fr/powershell/scripting/install/install-powershell-on-windows?view=powershell-7.5) ou autre) : 
```bash
# Installer la dernière vers LTS de Node.js
nvm install --lts
```

### Créer un tableau de bord

Pour créer un nouveau tableau de bord :

```sh
npm init @geo2france/api-dashboard@latest nom-du-projet
cd nom-du-projet && npm install

# Lancer le serveur de développement
npm run dev
```


### Gestion des pages

Le fichier `config.ts` peut-être édité pour personnaliser l'application : thème graphique, titre, routes, etc.

### Personnalisation

Le fichier `config.ts` expose plusieurs propriétés pour adapter l'apparence du tableau de bord :

```ts
// config.ts
export const config: DashboardConfig = {
  title: "Mon tableau de bord",

  // Preset de thème : 'geo2france' (défaut) ou 'neutral'
  theme: "geo2france",

  // Mode d'affichage : 'auto' (suit l'OS), 'light' ou 'dark'
  themeMode: "auto",

  // … autres options (routes, footer, etc.)
};
```

- **`'geo2france'`** — palette verte et bleue officielle Geo2France (`#95c11f`, `#0f4496`).
- **`'neutral'`** — palette bleue Ant Design générique, adaptée aux dashboards sans branding spécifique.
- **`'auto'`** — détecte automatiquement la préférence système (`prefers-color-scheme`).

Pour en savoir plus sur les possibilités de personnalisation avancée (override partiel, logo, typographie), consultez la page **[Theming](?path=/docs/documentation-theming--docs)**.

Pour tout ce qui concerne le mode sombre (intégration du bouton toggle, bonnes pratiques), consultez la page **[Dark Mode](?path=/docs/documentation-dark-mode--docs)**.
